# Transfer adapter: uniform

Base model: [Qwen/Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B); revision `060db6499f32faf8b98477b0a26969ef7d8b9987`.

Toy CausalMix demonstration: rank-8 LoRA on q/v projections, 16 optimizer steps, 256-token sequences, seed 42. These weights are the original final-run adapter weights.

See the snapshot README, configuration, manifest, and comparison records for data provenance and measured results. Training datasets: GSM8K (MIT), MBPP (CC-BY-4.0), and No Robots (CC-BY-NC-4.0). This is a research demonstration, not an evaluated chat assistant.
